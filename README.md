# Wardogs Mortar Calculator

Локальный калькулятор для миномёта L81 и арты SPH-2 в WARDOGS (Steam).

**Онлайн / Online:** https://officialdasper.github.io/wardogs_motar/
Local fire-control calculator for the L81 mortar and SPH-2 artillery in WARDOGS (Steam).

## Как пользоваться / How to use

1. Скачай `index.html` и открой двойным кликом в браузере. / Download `index.html` and open it in a browser.
2. Вбей свои координаты (A) и координаты цели (B) с карты, например `x98.43, y110.38`. / Enter your coordinates (A) and target (B) from the map.
3. Поверни миномёт на указанный азимут и выставь дальность. / Turn to the shown heading and set the range.

Формула: `дистанция = 100 × √(ΔX² + ΔY²)`, азимут 0° = север.

Языки: русский / English.
